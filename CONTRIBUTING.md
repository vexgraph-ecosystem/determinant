# Contributing

Read the complete [workspace constitution (preferences.md)](https://gist.github.com/vex-graph/4132a6c45cb6d3797c3e8eff2e94035a),
then [determinant-preferences.md](determinant-preferences.md), applicable
`tests/test-preferences.md`, current `gist/test-checklist.md`, and actual source.
Cite laws by Title. R3 borrows only R2 public contracts; no reverse R2 call or
R1/R4/R5/R6 implementation include. Keep terminal ownership resident across
reloadable code, caller-fed input and injected output; never overwrite a managed
screen with raw application printing.

Tests live in the independent `tests/determinant` tree, mirrored by production
unit, with fixtures under `fixtures`. Run registered owners strict C23 with
assertions and `-Wall -Wextra -Werror`, plus applicable sanitizers and bounded
watchdogs. The runner does not launch an interactive application or download
dependencies. Physical terminal and appearance acceptance belong to the user;
other platforms and unfinished integrations remain explicit gaps. Commit locally
per class only after documented proof; never push without a one-off instruction.
